# HoloCan · Configurador de envases Condensa

Aplicación web del configurador 3D de envases (versión instalable, funciona sin internet tras la primera carga).

- `index.html` — la aplicación completa (modelos 3D, voces, texturas y fuentes incrustados).
- `sw.js` — service worker: guarda la app en el dispositivo.
- `manifest.webmanifest`, `icon-*.png` — instalación en pantalla de inicio.

**iPad:** abrir la URL de GitHub Pages en Safari → Compartir → *Añadir a pantalla de inicio*. Abrir una vez con internet; después funciona sin conexión.
